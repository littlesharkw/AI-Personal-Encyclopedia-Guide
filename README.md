## WHY CLAUDE + CHATGPT?

### Claude

主要负责：

- Research
- Knowledge Architecture
- Master Index

对比多个 AI 后，
Claude 很适合整理大量知识、
长目录与学习结构。

任何 AI 都可能出错，
重要资料仍需核实。

### ChatGPT

主要负责：

- Visual Development
- Infographic Generation
- Sequential Automation
- Cover & TOC Design
- Final PDF Production

简单来说：

**Claude 负责把知识整理清楚。**

**ChatGPT 负责把知识画出来。**

## AUTOMATION

正式生产使用：

**FIRST RUN = SETUP + FIRST PAGE**

之后：

**ONE SCHEDULED RUN = ONE PAGE**

页面顺序永远按照
Official Master Index 的实际顺序读取，

而不是根据编号自行推算。

自动化可以减少大量重复操作，
但仍建议偶尔检查进度与生成结果。

## FINAL BOOK

所有正式页面完成后，

让 ChatGPT 参考：

**Official Master Index**

和：

**Official Visual Style Lock**

设计封面和完整目录。

目标不是普通文件目录，

而是让整套图鉴看起来像一本：

**真正出版的百科图鉴。**

ChatGPT 会根据实际内容
自行决定最适合的目录结构、
分页和版面设计。

然后把每一张封面／目录图的
独立生图指令分别给你，

让你逐张生成和确认。

确认满意后，

再合并：

**Final PDF**

最终 PDF 可以加入：

- Clickable TOC
- PDF Metadata
- Author Information
